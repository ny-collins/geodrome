Explore Geodesics & Diametric Antipodes

An interactive 3D spherical engine to plot great circle paths, calculate antipodal points, and visualize 2D Mercator projections in real-time.

Double-click globe to drop marker • Select heading for Great Circles • Toggle X-Ray for core tunnel lines

Geodesic Navigation

Plot orthodromic Great Circles across any bearing from 0° N to 315° NW. Watch animated 3D geodesic tubes grow in real-time led by traveling arrow indicators.

02 • Spherical Math

Antipodal Mathematics

Instantly calculate exact diametrically opposite coordinates. Enable core diameter lines to tunnel straight through Earth's center to its antipodes.

Simultaneously view dynamic WebGL 3D spherical rendering paired with synced 2D Mercator canvas projections with seam-clipping date line math.
